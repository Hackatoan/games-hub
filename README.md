# Games Hub

The landing hub for all Hackatoa browser games.

🔗 **Live:** [games.hackatoa.com](https://games.hackatoa.com)   ·   ☕ **Support:** [Buy Me a Coffee](https://buymeacoffee.com/hackatoa)

## Overview

A single front door linking every hosted browser game, with a cross-game aggregate leaderboard.

## Features

- Directory of all Hackatoa games
- Cross-game aggregate leaderboard
- 6-language localization

## Tech Stack

HTML · Node.js · Docker

## Deployment

Docker on the homelab games host; GHCR + Watchtower auto-deploy.
